# TFG-Hospital

![License](https://img.shields.io/badge/license-MIT-blue.svg)

## Descripción

**TFG-Hospital** es una aplicación web completa para la gestión hospitalaria, desarrollada como un Trabajo de Fin de Grado. El sistema permite administrar pacientes, citas, personal médico y otros aspectos clave de la operativa de un hospital.

La arquitectura del proyecto sigue un enfoque moderno de separación de responsabilidades, con un back-end robusto que expone una API REST y un front-end interactivo y responsivo.

## Arquitectura

El proyecto está dividido en dos componentes principales:

- **[Front-end](./front-end/README.md)**: Una aplicación de página única (SPA) desarrollada con Next.js y React, encargada de la interfaz de usuario.
- **[Back-end](./src/README.md)**: Una API RESTful construida con Spring Boot, que gestiona toda la lógica de negocio y la comunicación con la base de datos.

Para obtener información detallada sobre cada componente, su configuración y cómo ponerlo en marcha, por favor, consulta los `README.md` específicos de cada módulo.

## Características Principales

- **Gestión de Pacientes**: Alta, baja y modificación de la información de los pacientes.
- **Gestión de Citas**: Creación, consulta y cancelación de citas médicas.
- **Control de Personal**: Administración de médicos, enfermeros y otro personal del hospital.
- **Interfaz Intuitiva**: Un diseño de usuario limpio y moderno para una fácil navegación.
